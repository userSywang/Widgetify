# Widgetify 0.2.2 使用说明

## 打开新版

先退出正在运行的旧修改版，再打开安装包中的 Widgetify.app。新版沿用旧修改版的应用标识，通常会继续使用原有组件配置。原版 /Applications/Widgetify.app 未改动。

仅支持本次检查的 Apple 芯片版本。原有修改版的 Apple 天气服务授权限制继续存在。

## 文件夹集中管理

从屏幕顶部菜单“Widgetify → 文件夹集中管理”打开。通过“添加文件夹…”选择目录，也可将文件夹拖入新组件列表。

- 原路径直接位于桌面的文件夹：仅隐藏桌面图标，目录与内容保持原位。
- 其他位置的文件夹：只保存访问入口，不移动、不隐藏。
- 双击列表项或选中后点击“打开”，打开原文件夹。
- “恢复显示”恢复本组件隐藏的桌面图标；“隐藏桌面图标”可以重新隐藏。
- “移除管理”只删除入口，并恢复由本组件隐藏的图标，不删除原目录。
- 已经隐藏的文件夹不会被当作本组件隐藏，移除时不会擅自改变它原有的隐藏状态。
- “放到桌面”将组件放在桌面层，避免盖住普通应用窗口。需要管理时可再次从菜单打开。
- 文件夹列表和组件窗口位置会保存；重启应用后恢复入口。授权失败、目录被删除或不可访问时，可能需要重新添加。

本次新增的是独立的原生“文件夹集中管理”组件，原有“文档整理”的导入逻辑未改变。请把需要按上述规则管理的原文件夹添加到新组件中，旧组件的条目不会自动迁移。桌面文件夹内部的子文件夹不单独隐藏，以免影响原目录内部的显示。

卸载新版之前，请先在新组件中恢复所有桌面图标或移除所有管理入口。卸载应用本身不会自动改变文件夹的隐藏属性。必要时可在访达按 Command + Shift + . 临时显示隐藏项目，再重新添加恢复。

## 喝水定时提醒

从屏幕顶部菜单“Widgetify → 增强设置…”打开。

1. 填写每天的时间点，例如：09:30, 11:00, 14:00, 16:00。
2. 勾选“开启每日喝水提醒”，点击“保存提醒设置”。
3. 首次使用时允许系统通知。
4. 点击“发送测试通知”，约 3 秒后发送一条测试提醒。

最多 32 个不同的每日时间点，采用 24 小时格式。支持中文或英文逗号、空格及换行分隔，保存时会排序并去重。提醒按 Mac 当前时区每日重复。关闭开关并保存后，取消本模块的每日提醒；不会清除原应用其他功能的通知。

提醒默认关闭，避免未经设置就开始通知。横幅、声音、专注模式及休眠期间的送达行为受 macOS 设置影响。通知不会自动增加喝水记录，喝完仍需在喝水组件中记录。

## 已完成验证

- 新增菜单入口、增强设置界面与文件夹管理界面正常启动。
- 非法时间拒绝保存；有效时间规范化、排序、去重和保存正常。
- 每日通知触发器生成有效的下一次提醒时间。
- 非桌面测试文件夹路径、内容及显示状态保持不变，隐藏操作会被拒绝。
- 桌面测试文件夹添加后仅设置隐藏属性，文件仍位于原路径，内容校验一致。
- 恢复显示、再次隐藏、重启后恢复入口正常。
- 移除管理自动恢复桌面图标，原文件夹及内容仍在。
- 测试只使用了临时文件夹，已从桌面收回，未纳管或隐藏你的现有文件夹。
- 新版应用通过签名完整性检查。

尚未实际授予测试应用系统通知权限，因此未验证真实横幅送达。首次使用时请自行允许通知，再点击测试按钮核对。
