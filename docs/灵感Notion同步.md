# 灵感 Notion 连接

当前正式版为 0.2.15，双向同步细节见《灵感双向同步》。0.2.14 的单向同步为历史实现，已升级。

在灵感组件原有设置中保存内部连接密钥并开启同步。密钥存入本机钥匙串，不写入记录或 Git；软件签名变化时，macOS 可能要求账户本人重新授权。请在系统弹窗操作，不在聊天或代码中填写登录密码。

当前集成使用既定数据源及“创意、详情、日期、分类、优秀级、状态”属性。需在 Notion 向内部连接授予目标数据源访问权限。公开 API 标识不授予访问能力；密钥及数据源访问权限仍由用户管理。本版本的固定目标属于该定制工程，其他工作区需自行配置并适配数据源。

分类输入位于原标签位置，可选择已有选项或填写新名称；不存在的名称在同步时新建。新记录默认中优先级和未开始，使用原添加日期。补充写入原页面，时间固定为中国时区。原始记录先保存在本地，联网后发送；同步错误不回滚本地输入。

页面关联使用专用同步属性，补充使用时间标题的链接元数据；不在正文中显示内部编号。删除后统一在 Notion 垃圾箱恢复。与软件源码分开的私人 Git 历史继续保留。

隔离验证工具位于 experiments/notion-api-trial，正式构建不包含 live 测试驱动。构建预览不会安装、推送或创建 Release。任何 UI 更新都须先核对本次具体预览，再安装或发布。
