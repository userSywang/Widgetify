# Notion REST 接入验证工具

这些是隔离 Widgetify 进程内的历史调查及测试驱动，不编入正式应用。正式同步代码在 src/InspirationNotion.swift。

NotionTrial.m 验证直接连接、查重、写入、回读和测试页清理；PropertyTrial.m 验证属性、分类创建及追加顺序；SyncEngineLive.swift 和 BidirectionalLive.swift 用正式引擎验证同步。历史构建脚本可能依赖特定已安装版本，复现前需核对路径及测试配置。

凭据仅从用户明确提供的目录读取，不输出值或文件名，不放进安装包。临时副本只存在于私密测试容器，使用后删除。测试结果存在时拒绝自动重复执行；不明确的写入须先查证。双向测试复用明确指定的专用页面，不修改普通用户记录。不要把本机报告、数据快照或私人历史加入仓库。

真实测试验证过直接 API 请求、属性回读、时间追加和两端删除/Notion 恢复。公开源码不包含私人页面标识或实际笔记。用户须确认具体 UI 预览后才可安装或发布。
